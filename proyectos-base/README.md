# Proyectos base de React

- `mi-primera-app`: original de clase; composición App → Saludo. El useState importado no se usa en su pantalla.
- `pura-vida-react`: original de clase; página separada en Navbar, Hero, listas, tabla, contacto y pie.
- `conceptos-interactivos`: complemento nuevo; props, children, eventos, actualizaciones funcionales y comparación entre variable y estado.

En cada carpeta: `npm ci` y `npm run dev -- --port 5175` (usar un puerto distinto si se abren varias). `npm run build` comprueba la compilación. Las dependencias y dist no se entregan.

`ejercicio-solicitudes` no se incluyó porque el formulario y sus salidas todavía no tienen estado ni manejadores que resuelvan el ejercicio; importarlo no cubriría los conceptos que faltan.
