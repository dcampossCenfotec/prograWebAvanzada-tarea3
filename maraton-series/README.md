# Maratón de series - estado final acumulativo

Cliente React con Router, Express con MongoDB y servidor independiente de EF Core/SQL Server. Las instrucciones de instalación y ejecución de los tres procesos están en el [README de la entrega](../README.md). Los archivos .env no se copian; configurar las plantillas .env.example. Las conexiones SQL se guardan con user-secrets.

La documentación integrada está en [laboratorios](../docs/laboratorios.md), con capturas y respuestas. React usa Express para todas las operaciones; .NET solo implementa GET miembros y series. No contiene datos ni credenciales de Atlas dentro de la entrega.
