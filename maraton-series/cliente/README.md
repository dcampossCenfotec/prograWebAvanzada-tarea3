# Cliente React del Maratón

Estado final con Router, filtros en URL, detalle y operaciones persistentes contra Express/MongoDB. Ejecutar npm ci, copiar .env.example a .env y npm run dev. Puerto 5173 y VITE_API_URL=http://localhost:3000/api. npm run build genera la compilación.

Los recorridos, reflexiones y capturas se encuentran en [laboratorios](../../docs/laboratorios.md). Las respuestas originales de esta carpeta son históricas de las etapas locales; actualmente las series y miembros vienen del API, y los identificadores los genera MongoDB.
